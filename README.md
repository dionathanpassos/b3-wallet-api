#  API Rest - Login/Register de usuários com refresh token

##  Sobre o projeto
API REST desenvolvida em Java com Spring Boot para fest start de projetos.
Este repositório conta com cadastro e login de usuários gerenciados por JWT e refresh token.---

## Tecnologias propostas

- Java 17+
- Spring Boot
- Spring Security + JWT + Refresh Token
- Spring Data JPA
- MySQL
- Maven
- JUnit 5 + Mockito
- Bean Validation

---

## Funcionalidades

- Cadastro e gerenciamento de usuários.
- Autenticação e autorização por perfil.
- Tratamento padronizado de exceções.
- Testes automatizados das regras de negócio.
